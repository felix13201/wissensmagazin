# Wissensmagazin

Kostenlose GitHub-Pages-Website unter https://felix13201.github.io/wissensmagazin/.

## Veröffentlichung
Neue vollständige Artikel werden nach manueller Freigabe via GitHub-Integration in `articles.json` ergänzt. Die bisherige ChatGPT-Automation veröffentlicht nicht selbstständig.

## Datenschutz und redaktionelle Freigabe
Das öffentliche Magazin darf keinerlei personenbezogene Informationen über seinen Betreiber und keine nichtöffentlichen Informationen über Arbeitgeber, Kollegen, Kunden, interne Projekte, Tickets, IT-Systeme oder Netzwerkdaten enthalten. Interessen dürfen die Themenauswahl beeinflussen; Beispiele dürfen nur allgemein, seriös öffentlich belegt oder erkennbar fiktiv sein. Vor jeder Veröffentlichung ist eine Prüfung auf persönliche/vertrauliche Inhalte erforderlich. Keine unverifizierten Originalzitate oder erfundenen Quellen.

## Archiv
Unvollständige, nur rekonstruierte frühere Ausgaben wurden auf Wunsch entfernt. Nur vollständige freigegebene Artikel veröffentlichen.
