# Wissensmagazin

Statische Website für GitHub Pages.

## Veröffentlichung
Repository Settings → Pages → Deploy from a branch → main → /(root).

## Neue Artikel
In `articles.json` einen Eintrag mit `id`, `date`, `title`, `subtitle`, `category` und `content` hinzufügen. Der Artikel erscheint automatisch im Archiv.

**Wichtig:** Die vorhandenen Ausgaben sind Kurzfassungen. Eine automatische Veröffentlichung aus ChatGPT ist noch nicht eingerichtet.
